# 戏韵·新生 - 京剧文化数字体验平台

## 项目简介

《戏韵·新生》是一个融合传统京剧文化与现代数字交互设计的创新项目。通过沉浸式的网页体验，让用户以崭新的方式认识和参与京剧艺术。

### 设计理念

**「传统文化 × 数字体验 × 视觉叙事」**

以京剧传统美学为基础，结合现代 UI 设计语言，通过动态视觉、交互体验和多媒体展示，让用户从"观看京剧"转变为"参与京剧"。

## 项目特色

✨ **视觉设计**
- 东方美学 + 现代数字界面融合
- 中国红、墨黑、金色的经典色彩系统
- 脸谱、舞台、卷轴等传统元素的创新应用

🎭 **交互体验**
- 动态脸谱入口
- 沉浸式舞台空间
- 多种交互玩法

📱 **响应式设计**
- 完美适配各种屏幕尺寸
- 移动端友好

## 技术栈

- **前端框架**: React 18 + TypeScript
- **样式系统**: Tailwind CSS
- **动画库**: Framer Motion
- **路由管理**: React Router
- **状态管理**: Zustand
- **构建工具**: Vite

## 页面规划

1. **首页 (Home)** - 脸谱动效入口
2. **京剧文化介绍** - 历史、流派、角色
3. **经典剧目展示** - 舞台卡片、剧情介绍
4. **名家名段赏析** - 音视频播放
5. **互动体验** - 脸谱设计器、虚拟角色

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

浏览器会自动打开 `http://localhost:3000`

### 生产构建

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```
